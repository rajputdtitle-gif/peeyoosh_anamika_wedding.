PEEYOOSH & ANAMIKA — FREE WEDDING WEBSITE

This is a static website. It does not require Lovable, paid hosting, a credit card, or a custom domain.

To publish free with GitHub Pages:
1. Create a free account at https://github.com/
2. Create a PUBLIC repository named peeyoosh-anamika-wedding.
3. Extract this ZIP and upload index.html and the complete assets folder to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
6. GitHub will provide a free address like https://YOUR-USERNAME.github.io/peeyoosh-anamika-wedding/.
